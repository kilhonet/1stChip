## 소개

1stChip은 PC 안에 무엇이 들어 있는지 — CPU, 메인보드, 그래픽 카드, 멀티미디어, 랜 카드, 기타 기기 — 를 한 화면에 보여 주고, 장치마다 설치된 드라이버의 버전과 날짜를 함께 표시합니다.

Windows를 갓 설치한 상태에서도 동작합니다. 드라이버가 아직 없어서 장치 관리자에 "알 수 없는 장치"로만 보이는 장치도 제조사와 함께 목록에 나타나므로, 새로 설치한 뒤 어떤 드라이버가 빠졌는지 바로 확인할 수 있습니다.

압축을 풀고 실행하면 끝입니다. 설치 과정도, 관리자 권한도, 추가로 설치할 것도 없습니다.

## 주요 기능

- **한 화면 하드웨어 요약** — CPU, 메인보드, 그래픽 카드, 멀티미디어, 랜 카드, 기타 기기를 제조사 로고와 함께 표시합니다.
- **설치된 드라이버 버전과 날짜**를 장치 이름 아래에 보여 줍니다.
- **드라이버 없이도 검출** — 드라이버가 없는 장치도 제조사와 함께 목록에 나오고 `!` 표시가 붙습니다.
- **드라이버 업데이트 확인** — 목록을 1stChip 서버와 비교해 더 새로운 드라이버가 알려져 있으면 표시하고, 마우스를 올리면 사용 가능한 버전을 보여 줍니다.
- **클릭 한 번으로 드라이버 페이지** — `!` 표시를 클릭하면 해당 장치의 드라이버 페이지가 열립니다.
- **시스템 정보 줄** — 화면 아래에 CPU 클럭, 메모리 용량, Windows 에디션/버전을 표시합니다.
- **같은 장치는 하나로** — 동일한 장치가 여러 개면 `(×N)`으로 묶어서 보여 줍니다.
- **포터블** — 실행 파일 하나뿐이라 USB 메모리에 넣어 다닐 수 있습니다.
- **관리자 권한이 필요 없습니다.**
- **Windows 설정을 따릅니다** — 다크/라이트 모드는 Windows 앱 테마를, 화면 언어는 Windows 표시 언어(한국어, 영어)를 따릅니다.

## 사용법

### 기본 흐름

1. `1stChip.exe`를 실행합니다. 몇 초 안에 하드웨어 목록이 나타납니다.
2. 목록은 **CPU → 메인보드 → 그래픽 카드 → 멀티미디어 → 랜 카드 → 기타 기기** 순서로 정리되어 있습니다. 각 카테고리의 첫 줄이 대표 장치이고, 나머지 장치는 회색으로 이어집니다.
3. 장치 이름 아래 줄에 **설치된 드라이버의 버전과 날짜**가 보입니다.
4. 노란 `!` 표시가 있는 장치는 살펴볼 것이 있다는 뜻입니다. 마우스를 올리면 이유가 힌트로 뜨고, **클릭하면** 브라우저에서 그 장치의 드라이버 페이지가 열립니다.
5. 화면 맨 아래에 CPU 클럭, 메모리 용량, Windows 버전이 표시됩니다.

목록은 실행할 때 한 번 읽습니다. 드라이버를 설치한 뒤 결과를 확인하려면 1stChip을 닫고 다시 실행하세요.

### 화면 구성

| 위치 | 내용 |
|---|---|
| 로고 | 제조사 로고 (로고가 없는 제조사는 머리글자) |
| 장치 이름 | Windows가 붙인 이름. 같은 장치가 여러 개면 `(×2)`처럼 묶음 |
| 둘째 줄 | 설치된 드라이버 버전 · 날짜 |
| `!` | 드라이버 없음 / 문제 있음 / 더 새로운 드라이버 있음 — 마우스를 올리면 구분, 클릭하면 드라이버 페이지 |
| 아래 패널 | CPU 클럭(기본 클럭) · 메모리 용량 · 운영체제 |

### 이럴 때 이렇게

**Windows를 새로 설치했는데 어떤 드라이버를 깔아야 할지 모를 때**
1stChip을 실행하고 `!`가 붙은 장치를 찾으세요. 마우스를 올려 "드라이버가 설치되어 있지 않습니다"가 뜨면 그 장치가 빠진 것입니다. `!`를 클릭해 드라이버 페이지로 가서 설치한 뒤, 1stChip을 다시 실행해 `!`가 사라졌는지 확인합니다. 랜 카드 드라이버가 없어 인터넷이 안 되는 PC라면, 1stChip으로 랜 카드 제조사와 모델을 확인해 다른 PC에서 드라이버를 받아 오면 됩니다.

**장치 관리자에 "알 수 없는 장치"가 있을 때**
장치 관리자는 드라이버가 없으면 이름을 보여 주지 못하지만, 1stChip은 드라이버 없이도 제조사와 카테고리를 알아냅니다. 해당 장치가 어느 카테고리에 있는지 보고 `!`를 클릭하면 됩니다.

**드라이버가 최신인지 확인하고 싶을 때**
더 새로운 드라이버가 알려져 있으면 `!`가 붙고, 마우스를 올리면 "x.x.x 버전으로 업데이트할 수 있습니다"라고 알려 줍니다. `!`가 없으면 현재 알려진 범위에서는 최신입니다.

**내 PC 사양을 빠르게 확인할 때**
카테고리마다 첫 줄(대표 장치)만 읽으면 CPU·메인보드 칩셋·그래픽 카드·사운드·랜 카드가 한눈에 들어옵니다. 아래 패널에서 메모리 용량과 Windows 버전도 함께 확인합니다. 중고 거래 글을 쓰거나 게임·프로그램의 권장 사양과 비교할 때 편리합니다.

**같은 장치가 여러 개일 때**
동일한 장치는 한 줄로 묶여 `(×2)`처럼 개수가 표시됩니다. USB 허브나 내부 브리지처럼 사용자가 신경 쓸 필요 없는 구조적 장치는 목록에 나오지 않습니다.

**여러 대의 PC를 점검할 때**
1stChip은 설치가 필요 없고 관리자 권한도 필요 없으므로, USB 메모리에 넣고 다니며 PC마다 실행하면 됩니다. 실행한 PC에 흔적을 남기지 않습니다.

**인터넷이 안 되는 PC에서**
하드웨어 목록과 설치된 드라이버 정보는 인터넷 없이도 그대로 나옵니다. 다만 "더 새로운 드라이버 있음" 표시와 `!` 클릭으로 열리는 드라이버 페이지는 인터넷이 있어야 합니다.

**화면이 어둡게(밝게) 나오거나 영어로 나올 때**
1stChip은 Windows 설정을 따릅니다. 다크/라이트 모드는 Windows *설정 → 개인 설정 → 색 → 앱 모드*, 화면 언어는 Windows 표시 언어(한국어면 한국어, 그 외는 영어)를 바꾸면 됩니다.

프로그램은 한 번에 하나만 실행됩니다. 다시 실행하면 이미 열려 있는 창이 앞으로 나옵니다.

## 설정

설정 창은 없습니다. 1stChip은 Windows 설정을 자동으로 따릅니다.

| 항목 | 기준 |
|---|---|
| 라이트 / 다크 모드 | Windows *설정 → 개인 설정 → 색 → 앱 모드* |
| 화면 언어 | Windows 표시 언어 (한국어 → 한국어, 그 외 → 영어) |
| 날짜 형식 | 언어에 맞춤 (한국어 `yyyy-mm-dd`, 영어 `mm-dd-yyyy`) |

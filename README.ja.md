## 概要

1stChip は、PC に搭載されている CPU・マザーボード・グラフィックカード・マルチメディア・ネットワークカード・その他のデバイスを 1 つの画面に表示し、各デバイスにインストールされているドライバーのバージョンと日付をあわせて示します。

Windows をインストールした直後でも動作します。ドライバーがまだ入っておらず、デバイスマネージャーでは「不明なデバイス」としか表示されない機器も、メーカー名とともに一覧に現れます。クリーンインストール後にどのドライバーが足りないかを確認するのに便利です。

解凍して実行するだけ。インストール不要、管理者権限不要、他に入れるものもありません。

## 主な機能

- **1 画面でハードウェアを要約** — CPU、マザーボード、グラフィックカード、マルチメディア、ネットワークカード、その他のデバイスを、メーカーのロゴ付きで表示します。
- **インストール済みドライバーのバージョンと日付**をデバイス名の下に表示します。
- **ドライバーがなくても検出** — ドライバーのないデバイスもメーカー名とともに一覧に載り、`!` が付きます。
- **ドライバー更新チェック** — 一覧を 1stChip サーバーと照合し、より新しいドライバーが判明している場合はデバイスに印を付け、ツールチップで利用可能なバージョンを表示します。
- **ワンクリックでドライバーページへ** — `!` をクリックすると、そのデバイスのドライバーページが開きます。
- **システム情報行** — 画面下部に CPU クロック、メモリ容量、Windows のエディション/バージョンを表示します。
- **重複デバイスをまとめて表示** — 同一デバイスは `(×N)` として 1 行にまとめます。
- **ポータブル** — EXE ファイル 1 つだけなので、USB メモリに入れて持ち運べます。
- **管理者権限は不要です。**
- **Windows の設定に従います** — ダーク/ライトモードは Windows のアプリテーマに、表示言語は Windows の表示言語（英語・韓国語）に従います。

## 使い方

### 基本の流れ

1. `1stChip.exe` を実行します。数秒でハードウェアの一覧が表示されます。
2. 一覧は **CPU → マザーボード → グラフィックカード → マルチメディア → ネットワークカード → その他のデバイス** の順にまとまっています。各カテゴリの 1 行目が代表デバイスで、残りはグレーで続きます。
3. デバイス名の下の行に、**インストール済みドライバーのバージョンと日付**が表示されます。
4. 黄色の `!` は確認すべき点があるという印です。マウスを重ねると理由がヒントで表示され、**クリック**するとブラウザーでそのデバイスのドライバーページが開きます。
5. 画面の最下部に CPU クロック、メモリ容量、Windows のバージョンが表示されます。

一覧は起動時に一度だけ読み込みます。ドライバーをインストールした後に結果を確認するには、1stChip を閉じてもう一度実行してください。

### 画面構成

| 部分 | 内容 |
|---|---|
| ロゴ | メーカーのロゴ（ロゴのないメーカーは頭文字） |
| デバイス名 | Windows が付けた名前。同じデバイスが複数あれば `(×2)` のようにまとめて表示 |
| 2 行目 | インストール済みドライバーのバージョン・日付 |
| `!` | ドライバーなし / 問題あり / より新しいドライバーあり — マウスを重ねると区別でき、クリックでドライバーページ |
| 下部パネル | CPU クロック（ベースクロック）・メモリ容量・オペレーティングシステム |

### こんなときは

**Windows を入れ直したが、どのドライバーを入れればいいか分からない**
1stChip を実行して `!` の付いたデバイスを探します。マウスを重ねて「ドライバーがインストールされていません」と出れば、そのデバイスのドライバーが足りません。`!` をクリックしてドライバーページから入れた後、1stChip をもう一度実行して `!` が消えたか確認します。ネットワークドライバーがなくてインターネットにつながらない PC なら、1stChip でネットワークカードのメーカーと型番を確認し、別の PC でドライバーを入手してください。

**デバイスマネージャーに「不明なデバイス」がある**
デバイスマネージャーはドライバーがないと名前を表示できませんが、1stChip はドライバーなしでもメーカーとカテゴリを特定します。該当するカテゴリでデバイスを見つけて `!` をクリックしてください。

**ドライバーが最新か確認したい**
より新しいドライバーが判明していればデバイスに `!` が付き、マウスを重ねると「バージョン x.x.x に更新できます」と表示されます。`!` がなければ、判明している範囲では最新です。

**PC のスペックを手早く確認したい**
各カテゴリの 1 行目（代表デバイス）だけ読めば、CPU・マザーボードのチップセット・グラフィックカード・サウンド・ネットワークカードがひと目で分かり、下部パネルでメモリ容量と Windows のバージョンも確認できます。中古販売の出品文を書くときや、ゲームの推奨スペックと比べるときに便利です。

**同じデバイスが複数ある**
同一デバイスは 1 行にまとめられ、`(×2)` のように個数が表示されます。USB ハブや内部ブリッジなど、ユーザーが気にする必要のない構造的なデバイスは一覧に出ません。

**複数の PC を点検する**
1stChip はインストール不要で管理者権限も要らないので、USB メモリに入れて持ち歩き、PC ごとに実行すれば済みます。実行した PC には何も残しません。

**インターネットのない PC で**
ハードウェア一覧とインストール済みドライバーの情報はオフラインでもそのまま表示されます。「より新しいドライバーあり」の印と、`!` クリックで開くドライバーページだけがインターネット接続を必要とします。

**画面が暗い（明るい）、または英語で表示される**
1stChip は Windows の設定に従います。ダーク/ライトは Windows の*設定 → 個人用設定 → 色 → アプリモード*で、表示言語は Windows の表示言語（韓国語なら韓国語、それ以外は英語）で変わります。

同時に起動できるのは 1 つだけです。もう一度起動すると、すでに開いているウィンドウが前面に出ます。

## 設定

設定画面はありません。1stChip は Windows の設定に自動的に従います。

| 項目 | 参照元 |
|---|---|
| ライト / ダークモード | Windows *設定 → 個人用設定 → 色 → アプリモード* |
| 表示言語 | Windows の表示言語（韓国語 → 韓国語、それ以外 → 英語） |
| 日付形式 | 言語に合わせて表示（韓国語 `yyyy-mm-dd`、英語 `mm-dd-yyyy`） |

## 動作環境

- Windows 10 または Windows 11、**64 ビット**
- 管理者権限は不要
- インターネット接続は任意 — ドライバー更新チェックにのみ使用します

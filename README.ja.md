## 概要

1stChip は、PC に搭載されている CPU・マザーボード・グラフィックカード・マルチメディア・ネットワークカード・その他のデバイスを 1 つの画面に表示し、各デバイスにインストールされているドライバーのバージョンと日付をあわせて示します。

Windows をインストールした直後でも動作します。ドライバーがまだ入っておらず、デバイスマネージャーでは「不明なデバイス」としか表示されない機器も、メーカー名とともに一覧に現れます。クリーンインストール後にどのドライバーが足りないかを確認するのに便利です。

解凍して実行するだけ。インストール不要、管理者権限不要、他に入れるものもありません。

## 主な機能

- **1 画面でハードウェアを要約** — CPU、マザーボード、グラフィックカード、マルチメディア、ネットワークカード、その他のデバイスを、メーカーのロゴ付きで表示します。
- **インストール済みドライバーのバージョンと日付**をデバイス名の下に表示します。
- **ドライバーがなくても検出** — ドライバーのないデバイスもメーカー名とともに一覧に載り、`!` が付きます。
- **ドライバー更新チェック** — 一覧を 1stChip サーバーと照合し、より新しいドライバーが判明している場合はデバイスに印を付け、ツールチップで利用可能なバージョンを表示します。
- **ワンクリックでドライバーページへ** — `!` をクリックすると、そのデバイスのドライバーページが開きます。
- **システム情報行** — 画面下部に CPU クロック、メモリ容量、Windows のエディション/バージョンを表示します。
- **重複デバイスをまとめて表示** — 同一デバイスは `(×N)` として 1 行にまとめます。
- **ポータブル** — EXE ファイル 1 つだけなので、USB メモリに入れて持ち運べます。
- **管理者権限は不要です。**
- **Windows の設定に従います** — ダーク/ライトモードは Windows のアプリテーマに、表示言語は Windows の表示言語（英語・韓国語）に従います。

## 使い方

1. `1stChip.exe` を実行します。ハードウェアの一覧がすぐに表示されます。
2. カテゴリごとにデバイスが並びます。1 行目が代表デバイスで、残りはグレーで表示されます。
3. デバイス名の下に、**インストール済み**のドライバーのバージョンと日付が表示されます。
4. デバイスの横にある黄色の `!` は次のいずれかを意味します。
   - ドライバーがインストールされていない
   - デバイスが問題コードを報告している
   - より新しいドライバーが判明している — マウスを重ねるとバージョンが表示されます
5. `!` を**クリック**すると、ブラウザーでそのデバイスのドライバーページが開きます。
6. 下部のパネルに CPU クロック、メモリ容量、オペレーティングシステムが表示されます。

同時に起動できるのは 1 つだけです。もう一度起動すると、すでに開いているウィンドウが前面に出ます。

## 設定

設定画面はありません。1stChip は Windows の設定に自動的に従います。

| 項目 | 参照元 |
|---|---|
| ライト / ダークモード | Windows *設定 → 個人用設定 → 色 → アプリモード* |
| 表示言語 | Windows の表示言語（韓国語 → 韓国語、それ以外 → 英語） |
| 日付形式 | 言語に合わせて表示（韓国語 `yyyy-mm-dd`、英語 `mm-dd-yyyy`） |

## 動作環境

- Windows 10 または Windows 11、**64 ビット**
- 管理者権限は不要
- インターネット接続は任意 — ドライバー更新チェックにのみ使用します
